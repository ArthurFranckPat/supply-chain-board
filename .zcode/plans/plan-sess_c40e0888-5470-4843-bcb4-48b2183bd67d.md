# Sélecteur de date de référence — stock reconstitué à la date D

## Décisions actées
- **Date picker dédié** (mode single) dans l'en-tête du tableau
- **Tableau + totaux** se recalculent à la date D (cohérence globale)
- Défaut = aujourd'hui (stock actuel, comportement inchangé)

## Principe : `referenceDate` devient l'ancrage réel
Actuellement le repo ancre sur `STK_NOW` (snapshot ITMMVT d'aujourd'hui). Pour une date D passée, on calcule :
```
STK(D) = STK_NOW − Σ QTYSTU(mouvements entre D et aujourd'hui)
```
Concrètement, le rembobinage prend tous les mouvements **postérieurs à D** (pas seulement ceux de la plage affichée) et les retranche du stock actuel. Le flux est fetché de `from` à **aujourd'hui** (déjà le cas), donc on a tout ce qu'il faut.

## 1. MODIFIER `stock_valuation_repository.ts`
- `getStockValuationKpi(refDate, grain, from, to)` : `refDate` devient l'ancrage réel.
  - Aujourd'hui (`refDate ≈ now`) → comportement inchangé (STK_NOW).
  - Date passée → on retranche `Σ QTYSTU(mouvements > refDate)` de chaque article AVANT le rembobinage par période. Concrètement : `stkAnchor = stkNow − Σ(flux postérieurs à refDate)`, puis on rembobine `stkAnchor` sur les périodes `[from, to]`.
- Le snap de date X3 `ITMMVT` reste « maintenant » — c'est l'ancrage du rembobinage qui change, pas la source.
- `articles[]` est valorisé avec ce `stkAnchor × pmp` (cohérent avec les totaux).

## 2. `board_dataset.ts` — clé de cache inclut `refDate`
- `getStockValuation(grain, from, to, refDate)` — `refDate` ajouté à la clé de cache
  `stock-valuation:{grain}:{from}:{to}:{refDate}`. Chaque date de référence = son propre cache.

## 3. `dashboard_controller.ts`
- Passe `refDate` au cache (déjà parsé depuis `referenceDate` query param).

## 4. `dashboard.tsx` — date picker dédié dans la carte tableau
- Nouveau signal `stockRefDate` (défaut = `props.referenceDate` = aujourd'hui)
- Inclut `referenceDate=stockRefDate` dans le memo `stockUrl` → refetch au changement
- En-tête du tableau : bouton calendrier (icône `calendar_today`, `mode="single"`, popover) affichant la date ou « Aujourd'hui ». Bouton reset → revient à aujourd'hui.
- Les totaux du KPI valorisation (carte du haut) reflètent aussi cette date (même `stockUrl`).

## Vérifications
- Le flux est déjà fetché `from → aujourd'hui` → on a les mouvements postérieurs à n'importe quel `refDate` dans la fenêtre. ✅
- Si `refDate` est antérieur à `from`, le stock à D peut être négatif pour des articles mal approvisionnés (données X3) — on affiche tel quel (transparence), pas de clamp.
- Typecheck à valider après.
