## Refonte `ReceptionTableau` en bordereau (V3)

### Décisions arbitrées
- **Rail de date** : formatage côté client via `Intl.DateTimeFormat('fr-FR')` depuis `row.date` (ISO). Zéro modif serveur. Entorse isolée et documentée à la convention « serveur pré-formate ».
- **Filet comptable `3px double`** sur les totaux du jour : conservé (exception documentée à la grammaire hairline).
- **Couleur des palettes** : tous les tiers colorés (`chargeTier`/`chargeText` existants), aligné sur le calendrier — pas le restraint `<12` neutre du mockup.

### Verdicts de l'audit (déjà actés)
- **Rendu bespoke, pas DataTable** — la virtualisation à `<tr>` indépendantes est structurellement incompatible avec un rail vertical spanning + sous-totaux intercalaires. Volume réel ~30-60 lignes → virtualisation non critique.
- **Pattern à copier** : `inertia-react/components/board/poste-engagement-sheet.tsx:230-368` (`flex-1 overflow-auto` + insertion de groupe quand la clé change).
- **Signature `(rows, emptyState)` préservée** — seul consommateur = `receptions.tsx:290`.
- **Tri local supprimé** (interne, jamais remonté, payload serveur déjà trié date asc).
- Tokens conformes : `font-fraunces tabular-nums`, `text-suggere`/`text-destructive`, `rounded-lg` (14px), `border-b-2 border-foreground`.

### Fichier modifié
`inertia-react/components/receptions/receptions-views.tsx` — réécrire `ReceptionTableau` (lignes 65-259). **Intacts** : `ReceptionCalendrier` (l.265+) et les helpers `chargeTier`/`chargeBg`/`chargeText` (l.30-59, encore utilisés par le calendrier).

- `useState<SortingState>` + `useMemo` de tri (l.73-97).

- `Lightbulb`/`TriangleAlert` : garder seulement si réutilisés pour les notes de marge (estimé / coef manquant).

### Ajouts (internes au composant)
1. `groupRowsByDate(rows)` → `{ date: string|null, rows: ReceptionDisplayRow[] }[]` ordonné (Map, rows déjà triées serveur).
2. `formatRailDate(iso)` → `{ weekday, day, month }` via `Intl.DateTimeFormat('fr-FR', { weekday:'long', day:'numeric', month:'long' })`. Capitalisation du weekday (fr = minuscule par défaut). Relatif repris tel quel depuis `row.dateRelatif` (« auj. » / « +5j »), minuscule conforme serveur.
3. `sumPalettes(rows)` → somme des `nbPalettes` (0 pour coef manquant).
4. `distinctFournisseurs(rows)` → `new Set(rows.map(r => r.fournisseur)).size`.

### Pas de doc-head / doc-foot
Le masthead affiche déjà la range + total période ; la subbar affiche les compteurs coef manquant/estimés. Un en-tête/pied de bordereau les dupliquerait. La signature documentaire repose sur (1) le rail de date, (2) l'équation de conversion, (3) le total comptable à filet double — pas besoin d'encadrement supplémentaire.

### Filet double — exception documentée
Commentaire en tête du composant : la grammaire Airbnb prescrit des hairlines 1px, le bordereau fait une exception sur les totaux du jour (`border-b-[3px] border-double border-foreground`) pour la lisibilité comptable. Exception isolée, motivée.
